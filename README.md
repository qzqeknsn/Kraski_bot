# 🎨 Центр Красок #1 — Telegram AI-бот

Telegram-бот с AI-ассистентом для интернет-магазина **Центр Красок #1** (centr-krasok.kz).

Бот отвечает на вопросы о компании, товарах, услугах и условиях работы — без команд и меню, как обычный чат.

## ⚙️ Установка и запуск

### 1. Получить токен Telegram-бота

1. Напишите боту [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям — дайте имя и юзернейм боту
4. Скопируйте полученный токен (формат: `123456789:AAFxxxx...`)

### 2. Получить API-ключ Anthropic

1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com)
2. Перейдите в раздел **API Keys**
3. Создайте новый ключ и скопируйте его

### 3. Установить зависимости

```bash
# Клонировать проект
cd centr-krasok-bot

# Создать виртуальное окружение (рекомендуется)
python -m venv venv
source venv/bin/activate       # Linux/macOS
# или
venv\Scripts\activate          # Windows

# Установить зависимости
pip install -r requirements.txt
```

### 4. Настроить переменные окружения

```bash
# Скопировать пример
cp .env.example .env

# Отредактировать файл .env
nano .env
```

Или задать переменные окружения напрямую:

```bash
export TELEGRAM_TOKEN="123456789:AAFxxxx..."
export ANTHROPIC_API_KEY="sk-ant-xxxx..."
```

### 5. Запустить бота

```bash
python bot.py
```

Вы увидите:
```
🚀 Запуск бота Центр Красок #1...
✅ Бот запущен. Ожидание сообщений...
```

## 🤖 Возможности бота

### Режим работы
- Бот работает **без команд и меню** — пользователь пишет обычные сообщения
- Отвечает **на русском, казахском или английском** (в зависимости от языка вопроса)
- Поддерживает **контекст диалога** (помнит предыдущие сообщения в рамках сессии)

### Примеры вопросов

| Вопрос | Что ответит бот |
|--------|----------------|
| Чем занимается компания? | Описание магазина, ассортимент, позиционирование |
| Какие краски вы продаёте? | Категории товаров, бренды |
| Где находится офис? | Адреса в Алматы и Астане, режим работы |
| Какие бренды есть? | Список брендов (Dulux, Pinotex, Hammerite и др.) |
| Как сделать доставку? | Условия доставки, города |
| Есть ли скидки для дизайнеров? | Партнёрская программа |
| Сколько цветов можно заказать? | 45 000+ оттенков колеровки |
| Как связаться с магазином? | Телефоны, email, соцсети |

### Команды (опциональные)
- `/start` — приветственное сообщение
- `/help` — справка и примеры вопросов
- `/reset` — очистить историю диалога

## 🛡️ Защита от некорректных ответов

### 1. Системный промпт с базой знаний
AI получает полную информацию о компании и инструкцию отвечать **только на её основе**.

### 2. Явный запрет галлюцинаций
Промпт содержит правило: *"Никогда не выдумывай цены, адреса, телефоны или характеристики товаров"*.

### 3. Fallback-ответы
При вопросах вне базы знаний бот честно говорит: *"Такой информации у меня нет"* и предлагает позвонить или написать.

### 4. Защита от prompt injection
Фильтрация попыток взломать бота через сообщения типа *"игнорируй инструкции"*.

### 5. Ограничение длины сообщений
Сообщения длиннее 1000 символов отклоняются.

### 6. Ограничение контекста
Хранится только **последние 10 сообщений** — предотвращает манипуляции через длинный контекст.

## 🚀 Деплой на сервер

### Вариант 1: Простой VPS (systemd)

```bash
# Создать systemd-сервис
sudo nano /etc/systemd/system/centr-krasok-bot.service
```

```ini
[Unit]
Description=Centr Krasok Telegram Bot
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/centr-krasok-bot
Environment="TELEGRAM_TOKEN=ваш_токен"
Environment="ANTHROPIC_API_KEY=ваш_ключ"
ExecStart=/home/ubuntu/centr-krasok-bot/venv/bin/python bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable centr-krasok-bot
sudo systemctl start centr-krasok-bot
sudo systemctl status centr-krasok-bot
```

### Вариант 2: Railway.app (бесплатно для MVP)

1. Создайте аккаунт на [railway.app](https://railway.app)
2. Создайте новый проект → Deploy from GitHub
3. Добавьте переменные окружения в настройках
4. Деплой происходит автоматически

### Вариант 3: Docker

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["python", "bot.py"]
```

```bash
docker build -t centr-krasok-bot .
docker run -e TELEGRAM_TOKEN=xxx -e ANTHROPIC_API_KEY=xxx centr-krasok-bot
```
