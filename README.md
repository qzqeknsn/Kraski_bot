# Центр Красок #1 — Telegram AI-бот

Бот отвечает на вопросы о компании в режиме обычного чата. Пользователь пишет вопрос — бот отвечает на основе информации о магазине. Никаких команд и кнопок.

## Что нужно для запуска

- Python 3.10 или новее
- Токен Telegram-бота — получить у @BotFather
- API-ключ Groq — зарегистрироваться на console.groq.com, раздел API Keys, бесплатно

## Установка

Установите зависимости командой:

    pip install -r requirements.txt

Создайте файл bot.env в папке проекта и вставьте в него два ключа:

    TELEGRAM_TOKEN=ваш_токен
    GROQ_API_KEY=ваш_ключ_groq

Запустите бота:

    python3 bot.py

## Файлы проекта

bot.py — основной код бота, обрабатывает сообщения и общается с Groq API

company_knowledge.py — вся информация о компании: контакты, адреса, ассортимент, бренды, услуги

requirements.txt — список библиотек для установки

bot.env — ваши секретные ключи, этот файл не публиковать

## Что умеет бот

Отвечает на вопросы о компании — чем занимается, какие бренды продаёт, где находится офис, как оформить доставку, есть ли условия для дизайнеров и строителей. Если ответа нет в базе знаний — честно говорит об этом и даёт контакты магазина.

Помнит контекст разговора — можно задавать уточняющие вопросы без повторения.

Работает на русском, казахском и английском языках.

## Как обновить информацию о компании

Откройте файл company_knowledge.py и отредактируйте нужные данные. После сохранения перезапустите бота.
